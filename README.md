# Registration Form Validation

A simple Registration Form Validation project built using HTML, CSS, and JavaScript. This project performs real-time form validation for Name, Email, and Password fields using JavaScript regular expressions.

## Features

* Real-time input validation
* Name field accepts only letters and spaces
* Email validation using regex pattern
* Password validation with minimum character requirement
* Error messages displayed instantly
* Submit button enabled only when all fields are valid
* Responsive and beginner-friendly UI design

## Technologies Used

* HTML
* CSS
* JavaScript

## Learning Concepts

This project helps beginners understand:

* Form validation using JavaScript
* Regular Expressions (Regex)
* DOM manipulation
* Event listeners
* Button enable/disable functionality
* Basic responsive form styling using CSS
